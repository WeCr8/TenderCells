# Care scheduling (agent pack)

`care-agent-pack-2026-11-22/` is a specification and sample-data handoff for a solar, shade, weather and flock-aware care calendar.
It is **not deployed code**: start at its `README.md`, `AGENT_PROMPT.md` and `docs/IMPLEMENTATION_BACKLOG.md`.
Everything is simulation or review-only; no physical actions, no live schedules. Location in the samples is a deliberately coarse demo anchor.
Run the pack's smoke test with `python docs/scheduling/care-agent-pack-2026-11-22/tests/validate_package.py`.
