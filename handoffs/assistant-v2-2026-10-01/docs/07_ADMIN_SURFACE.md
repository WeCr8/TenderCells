# Platform admin surface

Keep the current customer guarantee that assistants cannot access other farms or Firebase/platform administration. Admin is a different surface.

Admin home: connector health, device connectivity, properties/customers, Builder validation, assets needing review, mission publication, firmware releases and demo health.

Builder Content: draft → validate → preview → publish → archive. Asset Library: `draft → reference-checked → instruction-ready`, with usage and validation errors. Every admin write should be audited with actor, timestamp, target and before/after/patch.
