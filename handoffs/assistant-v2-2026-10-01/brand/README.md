PNG files rendered locally from the exact authoritative SVG source reviewed from the live repository.

## Brand colors

- TenderCells green: `#147C38`
- Warm cream background: `#F7F4EE`

## Intended use

| Asset | Use |
|---|---|
| `official/tendercells-icon.svg` | authoritative rounded vector source |
| `official/tendercells-icon-square.svg` | authoritative full-bleed vector source |
| `official/tendercells-icon-1024.png` | high-resolution store/listing artwork |
| `official/tendercells-icon-512.png` | MCP server icon, Claude Desktop, store icon |
| `official/tendercells-icon-256.png` | medium UI |
| `official/tendercells-icon-128.png` | small UI |
| `official/tendercells-icon-64.png` | favicon/small UI |
| `official/tendercells-icon-square-1024.png` | stores that apply their own mask |
| `store-ready/*` | convenience copies for release workflows |

## Rules

- Do not redraw or substitute the logo for store submission.
- Do not recolor the green/cream mark unless a formal brand update is approved.
- Prefer the rounded icon when the platform does not apply its own mask.
- Prefer the square/full-bleed icon when the platform applies its own masking.
- Keep clear space around the mark.
- Do not put text inside the icon.
- Store the SVG as source of truth; derive raster sizes from it.
