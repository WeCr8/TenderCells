# CAD import

Open `CAD/STEP/00_FULL_ASSEMBLY_V3.step` in Fusion 360, SolidWorks, Inventor, Onshape, Creo or FreeCAD. Individual STEP bodies are supplied for each printed part. STL files are for slicing. The CadQuery source and parameter JSON are included for regeneration.

Vendor/reference electronics geometry lives under `Electronics/`. Replace generic envelopes with the exact purchased SKU where available.
