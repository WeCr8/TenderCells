# Actuator function check

- Six-pocket rotor angular pitch: 60 degrees.
- Default actuator: geared stepper capable of repeated full rotations.
- Hall sensor provides a recoverable zero/home reference.
- `POCKET_STEPS` must be calibrated to the specific 28BYJ-48 gearbox.
- MG996R direct drive is explicitly excluded from default six-pocket indexing.
