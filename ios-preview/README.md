# TenderCells local mobile shell

This Expo project opens the existing TenderCells farm OS in a WebView, with Farm, Animals, Schedule, Account, and Demo tabs. The first four tabs use the live `/app` routes; Demo remains available for public simulation. The same WebView retains the session across tabs so email/password sign-in on the Account page can be tested locally. It is separate from the unfinished native device-control prototype under `../app/`, and it is not a signed App Store build. Hardware commands, Google popup sign-in, and account persistence have not been verified on a device.

On the Mac mini, the Xcode workspace is `~/Projects/tendercells-ios-20261011/ios/TenderCells.xcworkspace`. A shortcut is in `~/Desktop/iOS-App-Projects/`. Xcode 27 and the iPhone 18 Pro simulator can build this locally without EAS cloud credits. The `expo-build-properties` scene support setting is required for iOS 27. The app icon uses the existing square TenderCells logo from this repository.

From this directory: `npm ci`, `npm run typecheck`, `npx expo-doctor`, `npx expo prebuild --platform ios --no-install`, then run `pod install` from `ios/` with a UTF-8 locale. Build the Release scheme for an iOS simulator, install the `.app` with `xcrun simctl install`, and inspect the result on the simulator. Android can be built locally with `npx expo prebuild --platform android --no-install` and `android/gradlew :app:assembleRelease`. The shell requires internet access to load the hosted farm OS.
