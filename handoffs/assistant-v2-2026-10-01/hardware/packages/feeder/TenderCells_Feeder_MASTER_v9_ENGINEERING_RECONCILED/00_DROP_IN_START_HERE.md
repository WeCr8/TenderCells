# Tender Cells Smart Feeder — v6 Global Drop-In

This release fixes the v5 brand/export and model-authority inconsistencies and adds a reusable Tender Cells CAD standard for future products.

## Start here
1. Read `00_MODEL_AND_BRAND_CORRECTIONS.md`.
2. For manufacturing/CAD, use only `CAD/CANONICAL/` plus individual STEP/STL parts as referenced by the master tables.
3. For SolidWorks/Fusion, start with `Global_CAD_Standard/`.
4. For developer/React Native work, use `App_Integration/` and the corrected mark-only icon family.
5. Treat `CAD/LEGACY_REFERENCE/` and the old interactive GLB as reference/behavior assets only.

**Neutral manufacturing authority is STEP. STL is printing output. GLB is visualization.**
