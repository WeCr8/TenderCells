# Stop Conditions

Stop implementation and report rather than guessing if:

- baseline tests fail for unrelated reasons;
- Builder JSON shape differs from the reviewed contract;
- a proposed tool requires bypassing per-user isolation;
- a hosted tool would need hardware writes;
- a Property Twin source cannot be identified;
- generated Builder content cannot be bundled deterministically;
- a technical Builder asset has no trustworthy readiness/provenance state;
- adding a tool requires weakening existing MCP annotations or safety checks;
- the requested change would route physical motion through Firebase/cloud;
- admin authorization cannot be separated from customer grants.
